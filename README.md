\# 🎯 Face Recognition Attendance System



A \*\*Full Stack Java + React + OpenCV + MySQL\*\* project that automates student attendance using real-time face recognition.



This system allows:

\- Registering students using a webcam

\- Training a face recognition model

\- Automatically marking attendance by recognizing faces



---



\## 🚀 Features



✅ Student Registration with Webcam  

✅ Face Data Stored in MySQL  

✅ LBPH Face Recognition Model Training  

✅ Real-time Attendance Marking  

✅ React Frontend  

✅ Java Servlet Backend  

✅ OpenCV Integration  



---



\## 🛠️ Tech Stack



\### Frontend

\- React JS  

\- react-webcam  

\- Fetch API  



\### Backend

\- Java Servlets (Jakarta)  

\- Apache Tomcat 11  

\- OpenCV (JavaCV + OpenCV Platform)  

\- JDBC  



\### Database

\- MySQL
